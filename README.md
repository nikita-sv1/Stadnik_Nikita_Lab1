# Лабораторная работа 1. Кто снизил активность и почему

Анализ синтетических данных банка «Меридиан»: снижение карточных оплат за 2024 год и январь-июнь 2025 года, обработка данных и выбор групп для кампании.

Основные файлы:

- `01_analysis.ipynb` — загрузка исходников, аудит, обработка и исследование.
- `02_report.ipynb` — бизнес-отчет из подготовленных данных.
- `report.pdf` — готовый отчет, 6 страниц и 4 графика.
- `cleaning_log.csv` — журнал решений по обработке.
- `campaign_list.csv` — итоговые `client_id` и `group`.

## Воспроизведение

1. Восстановить окружение Python 3.14: `uv sync --locked`.
2. Разместить персональные исходники в `data/raw/clients.csv` и `data/raw/transactions.csv`. Первый файл: UTF-8, разделитель-запятая; второй: Windows-1251, точка с запятой. Исходники не изменяются и не публикуются.
3. Зарегистрировать ядро: `uv run python -m ipykernel install --user --name bank-lab1 --display-name "Python (bank-lab1)"`. В Jupyter выбрать это ядро и из корня проекта выполнить сначала `01_analysis.ipynb`, затем `02_report.ipynb`, каждый в чистом ядре.
4. Подготовленные таблицы появятся в `data/processed/`, журнал и список кампании в корне.
5. Один раз установить браузер для экспорта: `uv run python -m playwright install chromium --only-shell`. Собрать PDF через `uv run python export_report.py`. Скрипт вызывает `nbconvert --to webpdf --no-input --execute` и учитывает несовместимость стандартного запуска Chromium с циклом событий `nbconvert` в Windows. В других системах можно использовать команду из задания: `uv run jupyter nbconvert --to webpdf --no-input --execute 02_report.ipynb --output report.pdf`.

Данные и окружение исключены из Git. Зависимости зафиксированы в `pyproject.toml` и `uv.lock`.

Учебные материалы и прежние версии сохранены локально рядом с проектом, в `../LAB_1_materials/`; для выполнения готовой работы они не нужны.
