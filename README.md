# Лабораторная №1. Кто снизил активность и почему

Исследование синтетических банковских данных: определить, у каких клиентов снизилось использование карт, и подготовить объяснимые правила кампании по восстановлению активности. Сравниваются 2024 год и январь–июнь 2025 года с учётом разной длины периодов.

Основной рабочий файл — `01_analysis.ipynb`. Блок I содержит постановку задачи, паспорт источников и диагностику качества без очистки. Ноутбук запускается сверху вниз из чистого ядра, рабочая папка — корень проекта.

Структура проекта: `01_analysis.ipynb` — исследование; `data/raw/` — неизменяемые исходники; `data/processed/` — результаты подготовки; `pyproject.toml` и `uv.lock` — окружение. 

Для воспроизведения нужны исходные файлы:

- `data/raw/clients.csv`: UTF-8, разделитель `,`.
- `data/raw/transactions.csv`: Windows-1251, разделитель `;`.

Окружение Python 3.14 восстанавливается командой `uv sync --locked`. В Jupyter нужно выбрать ядро этого окружения. Зависимости зафиксированы в `pyproject.toml` и `uv.lock`.
